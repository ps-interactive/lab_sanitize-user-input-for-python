# Sanitize User Input for Python
In this lab you will practice best practices in sanitizing user input accepted by a Python application.
The lab is dvided in two parts.

## SQL Injection
Here you will perform the following tasks:
- Examine a vulnerable method, containing string formatting, that talks to a SQLite database

- Exploit the SQL Injection in Python by bypassing a login query

- Prevent SQL Injection using parameterized queries


## Cross-Site Scripting (XSS) and Cross-Site Request Forgery (CSRF)
Here you will write a short Flask application and perform the following tasks
- Run XSS and CSRF exploits against the application

- Remediate the vulnerabilities
